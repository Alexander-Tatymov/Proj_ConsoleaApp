# TaskTracker

Автор: Татымов Александр, группа 25ИС-11Д
## Описание
Учебный проект: трекер задач (консольное приложение).

## План функций
1)	Добавить задачу
2)	Показать список задач
3)	Изменить статус задачи
4)	Удалить задачу
5)	Редактировать задачу
6)	Поиск по названию
7)	Фильтр по статусу
8)	Сортировка списка
9)	Сделать резервную копию (backup)
10)	Экспорт в файл (export)
11)	Импорт из файла (import)
12)	Статистика (отчёт)
13)	Экспорт отчёта в файл
14)	Показать последние строки лога
15)	Настройки (показать/сменить режим хранения)
16)	Экспорт в CSV
17)	Импорт из CSV (Replace/Merge)
18)	Расширенный поиск/фильтр
19)	Повторить последний фильтр
20)	Показать корзину
21)	Восстановить из корзины
22)	Очистить корзину (удалить навсегда)
23)	Архивировать задачу
24)	Показать архив
25)	Вернуть из архива
26)	Справка (Help)
27)	Диагностика
28)	Собрать отчёт для поддержки

## Стек
C# / .NET / Visual Studio

## Как запустить
1) Открыть solution в Visual Studio
2) Нажать F5 (Run)
3) В консоли появится меню
