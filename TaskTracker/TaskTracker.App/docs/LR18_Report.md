# Отчёт ЛР18 — config.json
## Что сделано
- Добавлены AppConfig и ConfigService
- Приложение читает config.json при старте
- Если config.json отсутствует или повреждён — создаётся дефо
лтный
- Пути к папкам (data/logs/backups/exports/reports) берутся и
з конфига
- Режим хранения берётся из StorageMode (или спрашивается при
AskOnStart=true)
- Добавлена команда 15) Настройки для смены StorageMode

## Как проверить
1) Удалить config.json и запустить -> файл создаётся
2) Поменять AskOnStart=true -> приложение спрашивает режим
3) Пункт 15 -> сменить StorageMode -> перезапустить -> режим
изменился
