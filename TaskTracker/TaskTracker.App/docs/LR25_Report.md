# Отчёт ЛР25 — архив

## Что сделано
- Добавлено поле IsArchived
- Активный список показывает только не удалённые и не архивные задачи
- Добавлены методы Archive, Unarchive и GetArchive
- Добавлены команды:
  - 24) Архивировать
  - 25) Показать архив
  - 26) Вернуть из архива

## Как проверить
1) Добавить 3 задачи
2) Архивировать одну -> она пропадает из списка
3) Открыть архив -> задача видна
4) Вернуть из архива -> задача снова в активном списке
