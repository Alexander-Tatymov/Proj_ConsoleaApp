# Отчёт ЛР21 — импорт с Merge
## Что сделано
- В TaskService добавлен MergeImport:
- объединяет задачи
- решает конфликт Id
- пропускает дубликаты
- В импорте добавлен выбор режима Replace/Merge
- Результат записывается в лог
## Как проверить
1) Создать задачи A и B
2) Подготовить файл импорта с конфликтующим Id
3) Import -> Merge -> убедиться, что задачи добавились
4) Import -> Replace -> убедиться, что список заменился
