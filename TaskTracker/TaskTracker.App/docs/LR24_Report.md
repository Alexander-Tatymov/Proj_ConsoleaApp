# Отчёт ЛР24 — корзина
## Что сделано
- Добавлено поле IsDeleted в TaskItem
- Delete отправляет задачу в корзину
- Основной список показывает только активные задачи
- Добавлены команды:
- 21) Показать корзину
- 22) Восстановить
- 23) Очистить корзину (Admin)
## Как проверить
1) Добавить 2 задачи
2) Удалить одну -> она пропадает из списка
3) Открыть корзину -> задача есть
4) Восстановить -> задача вернулась
5) Очистить корзину (Admin) -> удаление навсегда
